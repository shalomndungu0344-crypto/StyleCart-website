## Project Name
StyleCart Website

---

## Project Description
StyleCart is a simple front-end e-commerce clothing website that allows users to browse fashion products, add items to a shopping cart, and complete a checkout process.

The website is built using HTML, CSS, and JavaScript. It demonstrates core front-end development concepts such as DOM manipulation, event handling, and localStorage for data persistence.

The system works entirely in the browser (no backend) and simulates a real online shopping experience.

## Setup Instructions

1. Download or clone the project repository  
2. Open the project folder in a code editor (e.g., VS Code)  
3. Ensure all required files are included:
   - index.html
   - femme.html
   - gent.html
   - about.html
   - contact.html
   - styles.css
   - script.js

4. Open `index.html` in a web browser (Chrome recommended)

## Behaviour Driven Development (BDD)

| Feature            | User Action                          | Expected Behavior                              | Output |
|--------------------|--------------------------------------|------------------------------------------------|--------|
| View products      | Open website                         | Products are displayed                         | Items appear on homepage and category pages |
| Add to cart        | Click "Add to Cart" button          | Item is stored in cart (localStorage)         | Cart updates dynamically with item added |
| View cart          | Open cart icon/section              | Cart displays selected items                  | Items and total price shown |
| Remove item        | Click "remove" button on item       | Item is deleted from cart                     | Cart updates and total recalculates |
| Checkout           | Click "Checkout"                    | Checkout form appears                         | User enters details |
| Place order        | Submit checkout form                | Order is processed and cart cleared           | Alert confirmation + empty cart |
| Reset order        | Click "Reset Order"                 | Cart data is cleared                          | Page reloads with empty cart |
| Data persistence   | Refresh page                        | Cart data remains stored                      | Items persist using localStorage |
